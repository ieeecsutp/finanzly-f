## 📎 Descripción 
Finanzly es una aplicación web creada con Next.js que ayuda a los usuarios a gestionar sus finanzas personales, realizar un seguimiento de sus gastos, crear presupuestos y controlar sus deudas.

## ☝️🤓 Instalacion y Configuracion
> [!IMPORTANT]
> Debes tener instalado 
> - ⚙️ Node.js v20+ 
> - 📦 npm o yarn o pnpm como gestor de paquetes
> - 🔧 Git para control de versiones
> - 💻 Un editor de código (recomendado VSCode)
> - 🌐 Navegador Web - Chrome, Edge o Firefox

1. Clona el repositorio

```bash
git clone https://github.com/ieeecsutp/finanzly-f.git 
```

2. Instalar las dependencias

```bash
cd finanzly-f
npm install
# o
yarn install 
# o
pnpm install
```

3. Ejecuta el proyecto

```bash
npm run dev
# o
yarn dev
# o
pnpm dev
```


📌 Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
